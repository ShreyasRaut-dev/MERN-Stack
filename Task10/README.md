# Task 10
## Hero Section Image Animation

### Problem Statement
Continue the laundry website hero section and create an animation for the hero section image.

### Requirements
- Image should move continuously in a small orbit.
- Squeeze (compress) the image at some points of the animation using scaleX() / scaleY() or scale().
- Use @keyframes to create a smooth, continuous, and simple animation.

### Files Included
- index.html
- style.css
- laundry_hero.png

### How to Run
Open index.html in any web browser to view the automatic continuous animation.
