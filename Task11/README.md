# Task 11
## Thala 7 Sneaker Store

### Problem Statement
Create a simple sneaker selling website named "Thala 7 Sneaker Store" using HTML and CSS.

### Requirements
- 4 HTML pages: Landing Page, Product Page, Shopping Cart, Checkout.
- Single shared style.css file for all pages.
- Flexbox layouts for all sections.
- Simple, basic layout with typical student styling mismatches.

### Files Included
- landing.html
- product.html
- cart.html
- checkout.html
- style.css
- images/sneaker1.jpg
- images/sneaker2.jpg
- images/sneaker3.jpg

### How to Run
Open landing.html in a web browser to start, and click links to navigate between pages.
