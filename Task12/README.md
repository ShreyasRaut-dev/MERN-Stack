# Task 12
## Compound Interest Calculator

### Problem Statement
Write a JavaScript program to calculate Compound Interest using static values.

### Requirements
- Declare static variables for Principal (P), Rate (r), Compound Frequency (n), and Time (t).
- Calculate Total Amount (A) using A = P * (1 + r/n)^(n*t).
- Calculate Compound Interest (CI = A - P).
- Print values to console.log().

### Files Included
- index.html
- script.js

### How to Run
Open index.html in a web browser, press F12 (or right-click and Inspect) to open Developer Tools, and check the Console tab to view the printed output.
