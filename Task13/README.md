# Task 13
## Even or Odd Checker

### Problem Statement
Write a JavaScript program to check whether a number is even or odd using basic conditional logic and modulo operator.

### Requirements
- Declare 3 to 4 different variables with numbers.
- Use if-else conditional checks.
- Use modulo (%) operator.
- Display result using console.log().

### Files Included
- index.html
- script.js

### How to Run
Open index.html in a web browser, open the browser's console tab to view the output.
