# Task 14
## Number Operations

### Problem Statement
Write a JavaScript program to perform various mathematical checks and operations on a single given number (e.g. 153).

### Requirements
- Sum of first n natural numbers.
- Check if it is a palindrome.
- Check if it is a prime number.
- Find all factors.
- Sum of all digits.
- Check if it is an Armstrong number.
- Print everything to console.log().

### Files Included
- index.html
- script.js

### How to Run
Open index.html in a web browser, open the browser's console tab to see the output.
