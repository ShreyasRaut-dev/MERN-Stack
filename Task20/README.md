# Task: (JS) Project: Laundry Services Web App

Problem Statement: Design and implement a web application for a laundry service that allows users to explore services, book appointments, and receive email confirmations. The application should have a user-friendly interface with a navigation bar, hero section, service details, and a booking system.

Problem Description: The objective is to create a web application for a laundry service that streamlines the user experience. Users should be able to navigate through different sections, explore available services, add items to the cart, and book appointments seamlessly. Additionally, the application should send an email to your email address providing the details of the order placed by the user using email.js when the user clicks on Book Now.  

Tasks:  

Navbar:  

Design a responsive navigation bar with the following sections: Home, Services, About Us, Contact Us.  

Include a logo on the left and the user's name on the right.  

Hero Section:  

Create a hero section with two divs.  

Left div : Heading, description, and a "Book a Service Today" button. When a user clicks on the button it should scroll to the booking services section.  

Right div : Display an image related to the services.  

Service Overview Section:  

Design a section outside the main div with full width and some height.  

Display the service achievements: 15+ laundry services, 240+ happy customers, 2+ years of experience.  

Booking Services Section (Divide the section into left and right divs):  

Right Div:  

First div : Initially display no added items. Update dynamically as the user adds services from the right section (Note: The visual shows services on the left and cart on the right, please follow standard cart layout).  

Bottom of the first div : Display the total amount, initially set to 0.  

Second div: "Book Now" heading with input fields for full name, email, and phone number.  

"Book Now" button at the bottom of the second div.

Left Div:

Display services with the list of services, name, and price.

Include "Remove Now" and "Add Items" buttons for the services.

At the bottom, add info to "Add items to the cart".

Email Confirmation:

Implement email.js to send a confirmation email when the user clicks the "Book Now" button.

Display a message below the button "Thank you For Booking the Service We will get back to you soon!".

Quality Description Section:

Highlight unique selling points: premium services, quick support, timely delivery, and affordable prices.

Newsletter Subscription Section:

Incorporate input fields for the user's full name and email.

Include a "Subscribe" button.

Footer:

Include Logo, About Us Link, Important Links, Contact Us Link, and Social Media Icons.
