# Assignment: Responsive Food Delivery Landing Page (OmniFood Demo)

Problem Statement
You are a Junior Frontend Developer. Your task is to build a responsive, single-page landing website for a food delivery brand. The goal is to practice HTML structure + CSS layout + responsive design.

What You Need to Build (Sections)

Section 1: Header + Hero (Top Banner)
Must include: Logo on the left, Navbar items on the right (FOOD DELIVERY, HOW IT WORKS, OUR CITIES, SIGN-UP).
Hero headline text: "GOODBYE JUNK FOOD", "HELLO SUPER HEALTHY FOOD".
Two CTA buttons: Primary ("I'm Hungry"), Secondary ("Show me more").
Background image with dark overlay (text should be readable).

Section 2: How It Works (3 Steps)
Left side: Phone mockup image.
Right side: 3 numbered steps (Choose plan..., Pay for the plan..., You are done start ordering!!).
Below steps: Google Play + App Store buttons.

Section 3: Our Cities (4 Cards Grid)
Title: "WE'RE CURRENTLY IN THESE CITIES".
4 city cards: LISBON, LONDON, BERLIN, SAN-FRANCISCO.
Each card must include: City image, City name, Bullet-style details (happy eaters, chefs, handle).

Section 4: Testimonials (3 Quotes on Image Background)
Title: "OUR CUSTOMER CAN'T LIVE WITHOUT US".
3 testimonial blocks (quote marks + text).
Profile avatar + name under each testimonial.
Background image + dark overlay.

Section 5: Pricing Plans (3 Pricing Cards)
Title: "START EATING HEALTHY TODAY".
3 plan cards: PREMIUM ($399 / month), PRO ($199 / month), STARTER (19$ / meal).
Each card must include: Price text, Feature list with check/cross icons, "Sign up" button.

Section 6: Footer
Must include: Footer links on left (About us, Blog, Press, iOS App, Android App), Social icons on right, Copyright line.

Responsiveness Requirements (Mandatory)
Desktop (>=1200px): full layout as grid
Tablet (<=834px): sections stack nicely, grid becomes 2 columns where needed
Mobile (<=390px): single column layout, nav collapses (hamburger OR stacked menu)
