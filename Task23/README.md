# Task: Responsive Design & Layout Systems – AppName Landing Page

Objective: AppName is a modern SaaS platform designed to help teams build, collaborate, and launch products efficiently. The company wants to create a fully responsive landing page that adapts seamlessly across mobile, tablet, and desktop devices.

This HTML webpage demonstrates the implementation of Responsive Design using Tailwind CSS (CDN). The page showcases the use of mobile-first breakpoints, Flexbox, Grid systems, and responsive utilities to create a structured and adaptive layout.

The goal of this task is to build a responsive landing page using Tailwind's layout systems without writing custom CSS, ensuring proper alignment, spacing, and scalability across all screen sizes.

Tasks:

Responsive Navigation Bar:
Create a sticky navigation bar.
Display the logo "🚀 AppName" on the left.
Add navigation links: Features, Pricing, About, Contact.
Include a "Get Started" button.
Hide navigation links on mobile (hidden md:flex).
Show a mobile menu icon only on small screens (md:hidden).

Hero Section (Responsive Flex Layout):
Use a gradient background.
Create a flex container: flex-col on mobile (stacked layout), lg:flex-row on desktop (side-by-side layout).
Add a large responsive heading: "Build Amazing Products Faster".
Include a descriptive paragraph.
Add two buttons: Start Free Trial, Watch Demo.
Insert a responsive image with: Different heights for different breakpoints, Rounded corners and shadow.

Features Section (Responsive Grid System):
Add a heading: "Powerful Features."
Create a grid layout: grid-cols-1 on mobile, md:grid-cols-3 on tablets and larger screens.
Include three feature cards:
Lightning Fast (Optimized for speed and performance)
Secure (Enterprise grade security built in)
Analytics (Real time insights and reports)
Each card should contain: An icon, Title, Short description.
Add hover effects using Tailwind utilities.

Footer Section (Responsive Flex Layout):
Use a dark background.
Create a flex container: flex-col on mobile, sm:flex-row on larger screens.
Logo text "🚀 AppName".
Copyright text "2026 AppName. All rights reserved."
Ensure proper spacing and alignment.

Responsive Design Requirements:
Use Tailwind's mobile-first breakpoints: sm, md, lg, xl.
Use Flexbox utilities (flex, justify-, items-).
Use Grid utilities (grid, grid-cols-, gap-).
Use spacing utilities (p-, m-).
Maintain proper alignment and readable typography across devices.
Ensure the layout adjusts smoothly from mobile to desktop.
