# Task: Animations & UI Feedback – Interactive UI Design

Objective: Modern web applications require smooth animations and interactive feedback to enhance user experience. Animations help communicate system status, guide user attention, and improve engagement.
This HTML webpage demonstrates the implementation of built-in Tailwind animations, custom keyframe animations, transitions, hover effects, loading states, and interactive UI feedback components. The page focuses on enhancing UI responsiveness using Tailwind CSS utilities without writing complex custom CSS.
The goal of this task is to design an interactive UI demo page showcasing different animation techniques such as hover effects, button transformations, loading indicators, notification badges, and staggered animations.

Tasks:

Header Section:
Display a centered heading: "Animations & UI Feedback."
Add a short subtitle encouraging users to interact with elements.

Section 1: Built-in Animations:
Create four demo cards demonstrating Tailwind's built-in animations:
animate-spin (Loading spinner)
animate-ping (Notification pulse)
animate-pulse (Skeleton loader effect)
animate-bounce (Bounce indicator)
Each card should include: Animated element, Animation name, and Short description.

Section 2: Button Animations:
Create multiple interactive buttons demonstrating:
Scale effect on hover (hover:scale-110)
Shadow + scale combination
Background color transition
Rotate effect
Translate (lift) effect
Combined hover effects
Active state scaling (active:scale-95)
Use: transition, transition-all, transition-transform, duration-, ease-.

Section 3: Card Animations:
Create three interactive cards with:
Hover lift and shadow effect
Scale and rotate on hover using group-hover
Border reveal animation
Smooth transitions using duration-300

Section 4: Notification Badges:
Create interactive notification UI elements:
Bell icon with ping animation
Message icon with pulse animation
Email icon with bounce indicator
Use: relative and absolute positioning, Animated badges, Notification count indicators.

Section 5: Loading States:
Create different loading UI patterns:
Skeleton loader card using animate-pulse
Button with spinner using animate-spin
Bouncing dots loader with animation delay

Section 6: Staggered Animations (Delays):
Create animated cards that appear with:
Opacity transition
Fade-in animation
Different delay timings (0ms, 150ms, 300ms, 450ms)
Use: Custom @keyframes, animate-[...] syntax, Opacity and transform effects.
