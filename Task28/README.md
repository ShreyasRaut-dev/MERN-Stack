# Task: (ReactJS) Props

Problem Statement:
Create a React component for card that displays information passed as props.

Problem Description:
Your task is to develop a reusable card component that can render details from an array of objects passed as props. Also make sure that the cards should have a gradient border.

Visual Details (from reference):
Dark background.
A grid of cards.
Each card has a gradient border (purple/pink to red), an image in the center, a title (e.g., "Card 1"), and a small description below it.
