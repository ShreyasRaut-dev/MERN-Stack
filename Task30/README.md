# Task 27: (React Router DOM)

Problem Statement:
Your task is to implement navigation between different react routes using react-router-dom, allowing users to access different sections of the application.

Problem Description:
In this task, you will be introducing routing concepts in a React application to enable navigation between multiple views or pages. The application should have four main routes: Dashboard, Login, Signup, and Home.

Layout and theme totally upon your creativity but make sure it looks good enough and serves the purpose.
