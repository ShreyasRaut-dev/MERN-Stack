# Task: (ReactJS) Context API Payment

Problem Statement:
We already made a Shoe Website in previous Task. Lets take that one more step ahead and add a payment functionality in it. Implement this feature using the Context API in React. Upon clicking the "Proceed to Payment" button in the shopping cart, users should be redirected to a payment page.

Problem Description:
Your task is to add a payment functionality in the online shoe store using Context API for state management in React. The application should consist of following key components:

Proceed to Payment Button:
Add a "Proceed to Payment" button within the shopping cart. Upon clicking this button, users should be directed to the payment page.

Payment Page:
Create a payment page where users can view their shopping cart contents use context api to get cart items in payment page also. Include an option for users to return to shopping if they wish to add or remove items from their cart before making a payment.

Credit Card Payment:
Implement a form for users to enter credit card details.

Context API:
Utilize the Context API in React to manage the state related to the shopping cart.
