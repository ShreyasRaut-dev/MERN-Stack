# Task 32: React.js Offline Chess Game

Problem Statement:
Your task is to create a offline chess game where two players can play using React.js, where players take turns making moves. The game should enforce all legal moves, check, and checkmate logic. Additionally, implement timers for each player and display the move list in standard chess notation (e.g., e4, e5).

Problem Description:
In this task, you will develop a fully functional chess game using React.js. The game should support the following features:

Chess Board and Pieces:
Display an 8x8 chess board with pieces in their initial positions.
You can not use a library for this project.

Legal Moves:
Implement logic to validate legal moves for all pieces.
Prevent illegal moves and notify the player.

Turn-Based Play:
Alternate turns between two players (one move per turn).

Check and Checkmate:
Implement logic to detect check and checkmate conditions.
Notify players when a check or checkmate occurs.

Timers:
Implement countdown timers for each player.
Pause the timer for the inactive player during the opponent's turn.

Move List:
Track and display the list of moves made in standard chess notation.

Additional Features (Optional):
Implement undo functionality to revert the last move.
Highlight legal moves for the selected piece.
Display captured pieces for each player.
