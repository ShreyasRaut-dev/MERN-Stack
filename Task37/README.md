# Student Log - Workout Budyyy Application

This is my documentation for building the Workout Budyyy CRUD app.

## Learning Process:
- Refactored the single server file into a separate routing structure (/routes, /controllers, /models).
- Swapped context states to use correct spelling of state and dispatch to ensure clean, readable, and functional code.
- Created separate child components WorkoutDetails and WorkoutForm to consume the workouts context using the useContext hook.
- Configured MongoDB Atlas cloud database connection using a cluster URL.
- Coded CSS media queries to stack the two-column dashboard layout on mobile screens.
