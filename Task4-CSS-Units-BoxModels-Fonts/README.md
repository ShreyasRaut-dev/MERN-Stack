Task 4: CSS - Units, Box Models, Fonts

Problem Statement:
Develop a simple webpage to understand and practice CSS Units, Box Model, Viewport Units, and Font Styling.

Problem Description:
Create a webpage containing an image and a button. The page should use viewport units for spacing and proper box sizing to ensure the content fits within the screen without creating scrollbars.

Tasks
1. HTML Setup
Create an HTML file with the necessary HTML5 structure.
Set an appropriate document title.
Link an external CSS file (style.css).
2. Body Content
Create a <div> for displaying an image with an appropriate class name.
Insert an image inside the div.
Add a button below the image for user interaction.
3. CSS Styling
Give the webpage 25% spacing from the left and right sides of the screen.
Give 10% spacing from the top and bottom of the screen.
Style the button with:
A gradient background
Suitable font family
Appropriate font size
Text color
Padding
Rounded corners
Use box-sizing: border-box correctly.
Use Viewport Units (vw and vh) wherever required.
Ensure the webpage does not produce horizontal or vertical scrolling.

How to Run
1. Open index.html in any browser.
