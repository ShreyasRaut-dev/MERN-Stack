# Task 7: CSS - Laundry Services Responsive Issue

Problem Statement: Develop a responsive page for the laundry app we made in the previous Task.

Problem Description: We made the Hero Section of the laundry web app in a previous Task. But that works fine only on desktop when opened on mobile or tablet it breaks the layout we need to fix that using media Queries.

Tasks:

Navbar:

Text size for lists and logo and username gets smaller in tablet view.

Hide the links in the mobile view just show the logo and username in the navbar.

Instead of display: inline use Flex.

Hero Section:

Reduce the text sizes and image sizes in the tablet version.

Change the alignment and placing of image and text as shown in the sample output.

Hint: Try using flex-direction: column.

Layout Details based on Sample Outputs:

Desktop: The navbar contains a Logo on the left, "Home Services About Us Contact Us" in the middle, and a Username button on the right. The main section has the text "Revitalize Your Clothes with Expert Laundry Services!" with a description and a "Book a service today!" button on the left, and a 3D washing machine image on the right.

Tablet/Mobile: The layout breaks down to a single column. The text and button stack directly above the washing machine image. In mobile view, the center navbar links disappear entirely, leaving only the Logo and Username.
