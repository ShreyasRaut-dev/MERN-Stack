# Task 9
## CTA Button Hover Animation

### Problem Statement
Create a Call to Action (CTA) button with specific features and a smooth hover animation using CSS transitions and transforms.

### Requirements
- Bright blue background
- White text: "Book a service today!"
- Rounded corners
- No border
- Pointer cursor
- Hover animation: slightly bigger using transform: scale() and rotate slightly to the left (negative rotate)
- Smooth transition

### Files Included
- index.html
- style.css
- laundry_hero.png

### How to Run
Open index.html in any web browser and hover over the button.
